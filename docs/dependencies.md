## Installers

No third-party installer frameworks. Windows `Install.cmd` calls the helper and
`%SystemRoot%\System32\...\powershell.exe` (Unblock-File). macOS uses `/bin/sh`, `/usr/bin/xattr`,
`/bin/chmod`, and `pkgbuild` for the optional `.pkg`. All tools are called by absolute path.

## Controls

* Lockfiles: `native/Cargo.lock`, `extension/package-lock.json`, `xray.lock.json`. Builds use `--locked` and `npm ci`.
* Audits: `cargo audit` 0 vulnerabilities (1,261 advisories, re-run 2026-09-22), `npm audit` 0. CI runs both. Release manifest and checksums: [release-integrity.md](release-integrity.md).
* No runtime downloads: the product never fetches code. Xray updates are manual (bump the lock, run the tests, publish a new runtime).
* Updating Xray also requires reviewing `native/src/parse/fields.rs` against the new `infra/conf/*.go`.
